## 🧮 Descripción

Este proyecto contiene ejercicios prácticos de matrices, pensados para estudiar, practicar o preparar exámenes de programación en Java.  
Los ejercicios pueden incluir:

- Creación y manipulación de matrices  
- Recorridos por filas y columnas  
- Búsqueda de valores  
- Operaciones matemáticas básicas  
- Ejercicios tipo examen
